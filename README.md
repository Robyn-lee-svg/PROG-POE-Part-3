1.PROJECT OVERVIEW:
RaceDay is an Event Management System that was developed using ASP.NET Core. The system allows organisation
to manager aporting events and participants to register,enrol in events and view their results. Prt 3 extends the existing
RaceDay Rest API developed in Part 2 by introducing an ASP.NET Core MVC web application. The MVC application
communicates with the existing web API using HTTP requests it does not directly access the database.
